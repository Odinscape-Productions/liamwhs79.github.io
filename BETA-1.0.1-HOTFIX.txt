BERRY HAVEN BETA 1.0.1 HOTFIX

This package is ONLY for the Berry Haven relationship / Safe Space web app.

FIXED
- Restored normal document scrolling on standard pages.
- Removed competing body/main scroll locks outside the Talks workspace.
- Replaced overflow-x:hidden scroll-container behaviour with overflow-x:clip.
- Kept Talks and Berry Store internal scrolling where intended.
- Rebuilt the existing approved theme artwork for 1040x1440 phone delivery.
- Theme artwork itself is no longer continuously transformed or zoomed.
- Environmental CSS animation now happens above a stable wallpaper layer.
- Reduced mobile backdrop-filter load to improve Samsung/Chromium stability.
- Cache version bumped to berryhaven-beta-1-0-1.

IMPORTANT
The approved theme artwork originated from small 260x360 source images.
This hotfix makes those assets render much more cleanly and avoids repeated live scaling,
but a future art pass can replace them with newly generated native-HD wallpapers without
changing the theme engine.

UPLOAD
Replace ALL matching files from this ZIP in the GitHub repo root.
Then fully close and reopen the installed Berry Haven PWA.
